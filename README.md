# 성대 hack — 성균관대 인사캠 새내기 시설 지도

새내기를 위한 성균관대학교 인문사회과학캠퍼스 편의시설 지도입니다.
자판기·정수기·프린터·ATM·카페 등을 **한 단어로 검색**하면 어느 건물 몇 층에 있는지
현장 사진과 함께 바로 보여줍니다.

## 주요 기능
- 키워드 검색 (예: `자판기` → 건물별 위치·사진 목록)
- 건물 출입구·층별 편의시설, **문 닫는 시간**
- 현장 사진 (사람 모자이크 처리 · 위치정보 제거)
- 3D / 2D 캠퍼스 지도 (3D 로딩 실패 시 자동 2D)

## 배포
빌드 과정이 없는 **정적 사이트**라, 그대로 호스팅하면 됩니다.
- **Vercel**: 이 레포를 연결 → Framework Preset `Other`(정적) → 그대로 배포
- Netlify / GitHub Pages 등 아무 정적 호스팅도 동일

## 파일 구조
| 경로 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS 단일 파일) |
| `map3d.js`, `campus3d.json` | 3D 캠퍼스 지도 데이터 |
| `p/`, `t/` | 시설 사진 (p = 원본, t = 썸네일, WebP) |

## 데이터 출처
건물·시설 위치는 성균관대 공식 캠퍼스맵 기준, 현장 사진·문 닫는 시간은 팀원 현장 조사 기반입니다.
